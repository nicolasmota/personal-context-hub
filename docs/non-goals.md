# Non-goals

Personal Context Hub is not:

- an agent framework
- an orchestration framework
- a chatbot
- a vector database
- a retrieval framework
- a personal assistant
- an integration platform
- a model
- a hosted service

This repository does not ship provider integrations, a marketplace, cloud sync, a desktop shell, or a web interface.

Imported material, if a future ingest path exists, is data. It does not expand grants, change policy, or act outward.
